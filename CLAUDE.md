# Project notes

Keep facts here; AGENTS.md is generated by `next dev`.

## Status

- v2.0.0 fresh start: Next.js App Router, TypeScript, Tailwind v4 (PostCSS),
  Vinyaas, lucide-react. Static data in `src/data/*.ts`.
- Pages in `src/app/`; shared pieces in `src/components/site/`.
- Not built: contact storage, resume PDF (removed in reset), admin, database.
  Experience/education content is edited by hand in `src/data/experience.ts`
  until the admin settings page exists — don't claim it's live-editable.

## Vinyaas

- Add with `npx vinyaas@1.4.0 add <name>`; never copy files. Check with `doctor`.
- `components.json` is from `init`. Don't re-run `init`: it rewrites `globals.css`.
- Components: `src/components/ui/<name>/index.tsx`. `cn`: `@/lib/utils`.
- Vinyaas `CardTitle` is a `div`; `Badge` has only shadcn variants.

## Theme

- `globals.css`: shadcn palette (orange primary, `--radius` 0.5rem) as given in
  the brief; `--glow`, `--mesh-*`, `--logo-glow` are project extras. Layout sets `dark`.
- Use semantic utilities (`bg-primary`, `text-muted-foreground`).
- Motion: `fade-up`, `lift`, `glow-breathe`, `timeline-grow`, `timeline-dot`;
  stagger via `style={{"--delay": ...}}`. All respect reduced motion.
- `src/components/site/timeline.tsx`: left-rail timeline (icon dots + a
  gradient line + achievement checklist), used by `/experience` for both work
  and education. `PublicExperience.kind` ("work" | "education") picks the
  icon and which section an entry lands in.

## Token-saving

- Pipe long output through `tail -n 30`/`grep`. Never print registry JSON.
- Don't read the backup tarball or the aavedak repo unless needed.
- Checks: `npx tsc --noEmit`, `npm run lint`, `npx prettier --check .`.
